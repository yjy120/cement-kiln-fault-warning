水泥窑线故障预警系统 —— 队友上手说明（照着做就行）

【一、第一次准备，只做一次】
1. 装 Node.js：浏览器打开 nodejs.org，下载 LTS 版，一路"下一步"装完（不用改设置）。
2. 装 Git：打开 git-scm.com，下载安装，同样一路下一步。
3. 把项目拉到自己电脑：在 D 盘新建一个文件夹（比如 D:\cement），
   在里面空白处按住 Shift + 鼠标右键 → "在此处打开 PowerShell / 终端"，输入这行后回车：
   git clone https://github.com/yjy120/cement-kiln-fault-warning.git
4. 进入刚下载出来的 cement-kiln-fault-warning 文件夹，
   双击「一键安装依赖.bat」，等黑窗口跑完（出现 Done 就好）。
5. 双击「一键启动.bat」，浏览器自动打开页面 → 项目就跑起来了。

【二、以后每次干活就三步】
第 1 步：双击 pull.bat
   —— 把别人改的代码拉到你电脑。每次动手前先做，必做！
第 2 步：改代码
   —— 用 VS Code 打开 cement-kiln-fault-warning 文件夹，
      只改分给你的那几个文件，别动别人的。
第 3 步：双击 submit.bat
   —— 它会自动把你改的存好、上传到 GitHub。
      看到黑窗口出现 "main to main" 或者 Done 就成了。

【三、三个必须记住的规矩】
1. 干活前先 pull，改完马上 submit，别攒着不改也不传。
2. 各改各的文件，别两个人同时改同一个，不然会"冲突"（报错发群里）。
3. 传之前确认 GitHub 能打开（代理/VPN 开着），不开会传不上去。

【四、传不上去 / 报错怎么办】
- 任何红色报错：直接把黑窗口截图发群里，我帮你看。
- 中文 bat 窗口里字是乱码：不用管，那是显示问题，命令照样执行，看最后有没有 Done。
